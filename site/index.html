它做什么

不是随机撒几段铁轨，是按一张真正的路网来规划。

路网规划

在每个 4096×4096 分区里用低差异序列撒 8~12 个候选站点，做德劳内三角剖分，再剪掉夹角过小（<70°）和度数超过 4 的边，得到一张不会挤成一团的网。

车站与岔站

按节点度数自动选型：只连两条线的站用两出口直线站，连到三条以上的站用四出口岔站。出口方向会自动旋转，挑朝向邻站的那一面。

地形适应

撒点阶段就跳过海洋与河流；连线阶段规划坡度安全的纵断面，坡太陡或跨水需要时自动架桥、钻洞，而不是硬怼一条斜线穿山。

双线轨道 1.3.0 新增

两条平行轨道并排铺设，间距可调（2~8 格，默认 3）。第二条线由整条路径整体平移生成，全程首尾相接，车站出口处以浅弯分岔并入。

跨区域连通 1.3.0 新增

相邻两个分区会在公共边界上取同一个对接点（坐标与高度都由共享种子算出），两边的轨道在边界处头对头接上，路网不再是一块块孤岛。

生成范围可控

可以只在出生点附近按概率生成，也可以打开「全世界生成」让每个分区都有铁路。范围、概率都在配置里改，不用重开存档。

配置

文件位置：config/zongheng_railway-common.toml。改完重进世界生效。

键默认说明
generateRailwayEverywheretrue全世界生成。开启时忽略距离上限与概率，每个分区都会生成路网。
areaGenerationRailwayProbability0.4未开启全世界生成时，每个分区生成路网的概率（0~1）。
maxRegionDistance100未开启全世界生成时，以分区为单位限制生成范围。
connectAcrossRegionstrue跨区域连通。关掉后每个分区各成一张独立的路网。
doubleTrackEnabledtrue双线轨道。关掉就是单线。
trackSpacing3双线间距（2~8 格）。窄桥模板是 5 格宽，间距 3 刚好能塞进桥面。
enableTrackSpawnertrue启用轨道生成器相关逻辑。
generateTrackSpawnertrue生成轨道生成器。
placeTracksUsingTrackSpawnertrue用轨道生成器来铺轨。

安装

1

装好前置

Minecraft 1.21.1 + NeoForge 21.1.x，再装 Create 6.0.6。Ponder 与 Flywheel 由 Create 自带，不用单独装。

2

放 jar

把 zongheng_railway-1.3.0+mc21.1.jar 放进 mods/。客户端和服务端都要放。

3

进世界

新世界会在区块生成时自动铺轨；旧世界只影响之后新生成的区块。找车站可以用 /zongheng_railway searchstation，加 large / small 只找大站或小站。

和上游能不能一起装？

不能。mod id 不一样（zongheng_railway），但同时装会出现两套一模一样的路网互相重叠，请只保留一个。
